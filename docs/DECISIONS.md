# Решения — ToonExpo Feedback

Короткие записи. Формальные ADR — только если решение спорное.

---

## 2026-09-10

- Размер проекта **A**. Одна публичная форма, без админки и без отдельного backend.
- Хостинг **Vercel + Next.js**. Домен **feedback.toonexpo.com**.
- База **Neon** (строка уже у разработчика). Прод-URL не держать в локальном `.env` для ежедневной работы.
- Админки не будет. Серверный POST всё равно нужен: ключи Neon и Google нельзя отдавать в браузер.
- Google Sheet: таблица `1nGBUK_Do0MZZ-RzN4MSeJpFuJ-RpQUzrgnDTdBkVJBY`. Пишем через **Apps Script webhook**, без Google Cloud и service account. Совсем без секрета нельзя: публичная ссылка не принимает строки. URL вебхука держим в env.
- Сначала Neon, Sheet можно позже (after + cron). Пользователь не ждёт Google.
- Дизайн: логотип и палитра из [ToonExpo_Registration](https://github.com/neetrino/ToonExpo_Registration), без градиента, более плоский современный UI.
- Антибот: honeypot + валидация, без капчи и без Redis.
- Нагрузка: рассылка ~2000, сильного пика не ждут; запас — короткий INSERT и асинхронный Sheet.
- **Языки:** армянский и русский (`hy`, `ru`). Английский не делаем. `next-intl`, URL `/hy` и `/ru`, первый визит `hy`, дальше cookie.
- **Персональные данные не собираем.** Ответ 2026-09-10: «persnalani dnaniey en soberaym». В форме, Neon и Sheet нет имени, телефона и email.
- **Вход в анкету:** две карточки на главной («Я был» / «Я не пришёл»), затем `/visited` и `/missed`. Прямые ссылки можно слать в разных письмах.
- **Лимиты БД:** pool 5, `statement_timeout` 10s, idle 10s, `lock_timeout` 5s.
- Лимиты БД согласованы. Код приложения не пишем, пока явно не скажут стартовать реализацию. Webhook Sheet заводим вместе с кодом.
- 2026-09-10: в таблице созданы листы `Visited` и `Missed` с заголовками.
- 2026-09-11: в Sheet пишем армянские человекочитаемые названия листов, заголовки и ответы. В Neon по-прежнему коды.
- 2026-09-10: реализация стартовала по явной просьбе. Sheet пишем через Apps Script `doPost`; секрет в JSON-теле, потому что кастомные заголовки скрипт часто не видит. Прод-миграции — GitHub Actions `prisma migrate deploy`, не с ноутбука.
- UI: официальные lockup/favicon из Registration. Светлая страница + тёмный бренд-хедер. Анкеты по шагам, «спасибо» с зелёной галочкой. Без градиентов и Framer Motion.
